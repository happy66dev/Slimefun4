## 维护约定

- 行为说明以当前代码为准，尤其是连接范围、限流、老化、机器损坏和权限默认值。
- `energynet-spec.md` 作为实现细节的主文档，玩家手册只描述实际可操作行为。
- 验证文档中的测试用例应覆盖新增物品、命令、异步初始化、自调度和数据持久化。
- 审计报告只记录发现的问题，不直接代表已修复状态。
