### 电网三阶段异步架构

```
Phase 1 [主线程]: tickAllGenerators() + tickAllCapacitors() + collectTickSnapshot()
Phase 2 [异步]:   GRID_TICK_EXECUTOR → computeTransfers(snapshot)
Phase 3 [主线程]: applyTransferResult() → storeRemainingEnergy + meters + aging + stats
```

**关键改动**：`scheduleSelfTick` 从 `runTaskTimerAsynchronously` → `runTaskTimer`（主线程调度），所有 Bukkit/Storage I/O 限定在主线程 Phase 1/3，异步 Phase 2 仅执行纯数学计算。
