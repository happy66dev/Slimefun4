# 粘液科技电网系统 — 玩家手册

## 概述

本服务器对粘液科技原版电力网络进行了全面重构。如果您熟悉原版粘液科技的电力系统，以下内容将帮助您快速了解新机制的变化。

**核心理念**：电力网络从"被动发现"变更为"主动组网"，以**能源调节器**为核心构建集中式电网，支持预计算最短路径传输、连接器负载记录，为后续过载机制预留接口。

***

## 一、电网基本概念

### 1. 能源调节器（核心）

每个电网有且仅有一个能源调节器。它是电网的"心脏"——负责控制电力分配、管理成员、显示电网状态。

- **放置**：放置后自动初始化电网
- **拆除**：整个电网立即销毁，所有机器回归无电网状态
- **状态显示**：调节器上方全息文字多行显示电网状态（电力净差额、本tick产出/消耗、当前储能/最大容量）

### 2. 电网成员

| 类型      | 功能   | 说明                               |
| ------- | ---- | -------------------------------- |
| **连接器** | 传输电力 | 不同等级的连接器有不同的连接范围（3/4/5/6/10/18格） |
| **长途连接器** | 远距传输 | 范围128格，只能连接6个方向上最近的连接器，有老化耐久机制 |
| **电量计数器** | 统计电量 | 放在连接器上方一格，统计经过该连接器的累计电量 |
| **限电器** | 限制流量 | 放在连接器上方一格（与电量计数器二选一），限制每tick最大通过电量 |
| **发电机** | 产生电力 | 太阳能、火山发电机等                       |
| **用电器** | 消耗电力 | 各类机器                             |
| **电容器** | 储存电力 | 相邻电容可自动串联成"电容子网络"                |
| **货运管理器** | 消耗电力 | 货运网络调节器，接入电网作为用电器运行，可变容量 `128+4×输入节点数` J |

### 3. 连接范围

每个连接器有一个**连接范围**值（如3、5、10、18），表示它可以在该半径的长方体区域内传输电力。

不同等级连接器：

| 连接器     | 连接范围 | 说明  |
| ------- | ---- | --- |
| 基础能源连接器 | 3格   | 入门级 |
| 能源连接器   | 5格   | 普通级 |
| 强力能源连接器 | 4格   | 中级  |
| 镀金能源连接器 | 6格   | 高级  |
| 强化能源连接器 | 10格  | 顶级  |
| 碳金能源连接器 | 18格  | 终极  |
| 长途连接器   | 128格 | 特殊级 |
| 电量计数器   | —    | 统计级 |
| 限电器       | —    | 限制级 |
| 电容       | —    | 储能级 |

**注意**：连接器之间是单向连接——只需要发送方连接器的范围覆盖目标即可。例如范围18的连接器可以单向连接到范围3的连接器（距离≤3），但范围3不能主动连接范围18的连接器（除非距离也在3内）。

## 二、组建电网

### 步骤1：放置能源调节器

- 在目标位置放置调节器
- 调节器会显示"初始化电网中..."的全息文字
- 初始化完成后显示电力净差额 + 本tick产出/消耗 + 当前储能/最大容量（多行全息）

### 步骤2：放置连接器

- 在调节器周围6格内放置连接器
- 连接器会自动被调节器发现
- 连接器会探索其连接范围内的所有设备

### 步骤3：放置发电机/用电器/电容

- 这些设备必须在**连接器的连接范围内**才能接入电网
- 放置后电网会自动重新初始化

## 三、连接规则（重要）

### 有效连接

```
[连接器A(范围18)] → [连接器B(范围3)]    ← 单向：A范围18覆盖B，但B范围3不能覆盖A
    ↓                       ↓
[发电机]              [用电器]
    ↓
[电容] ←→ [电容]  ←→ [电容]
                                    ← [长途连接器(范围128)] → [其他连接器]
```

- **连接器→连接器**：只需**发送方连接器的范围覆盖目标**（单向）\
  ⚠️ 高范围连接器可以单向连接到低范围连接器，反之不行。\
  例：范围18的连接器可以连接范围3的连接器（距离≤3），但范围3不能连接范围18（除非距离≤3）如果出现单向连接情况，那么电力只可以单向运输。
- **连接器→连接器（含长途连接器）**：如果目标/源是长途连接器，使用其128格范围进行连接验证
- **长途连接器→连接器**：只连接6个轴向上最近的连接器（每个方向只连第一个遇到的连接器，遇任意方块即停）。**双向校验**：目标连接器也必须能用自身范围覆盖长途连接器，否则该方向不建立连接。这相当于要求 `distance ≤ min(range_长途, range_目标)`，实现双向连接器间的**完全隔离**——小范围连接器无法接入长途网络。
- **连接器→发电机/用电器/电容**：只需**连接器的范围覆盖目标**
- **发电机→连接器**：只需**连接器的范围覆盖发电机**
- **电容↔电容**：仅需**相邻**（6个方向），不检查范围
- **电容→连接器**：电容必须**相邻**连接器，且连接器范围覆盖电容

### 无效连接

```
[用电器] ←→ [用电器]
```

用电器不能作为电力发送方，它们之间无法建立连接。

### 举例：连接器范围覆盖

```
A(用电器) × × 3(①) 3(②) 3(③) × B(用电器)
```

在这个布局中：

- ① 范围3可以覆盖A（距离3格内）
- ①→②：①范围3覆盖②（距离1）✅；②→①：②范围3覆盖①（距离1）✅ → 双向均可
- ①→③：①范围3覆盖③（距离2）✅；③→①：③范围3覆盖①（距离2）✅ → 双向均可
- ③→B：③范围3覆盖B（距离1）✅
- **A→①→③→B** 路径可用，长度为2（经过2个连接器）
- **A→①→②→B** 路径可用，长度为2
- 两条等长最短路径会被同时保留，电力均摊

## 四、电力传输

### 传输规则

每个游戏刻（tick），电网会执行以下流程：

1. **汇总**：计算总发电量 vs 总用电量
2. **按最短路径优先**：从最短的电力路径开始传输
3. **按需传输**：只传输用电器需要的电量

#### 发电充足时（发电 ≥ 用电）

- 仅使用发电机供电
- 从最短路径→最长路径遍历

#### 发电不足时（发电 < 用电）

1. 先用所有发电机供电
2. 再用所有电容器放电补充

### 路径选择

对于同一个发电机到同一个用电器的多条路径：

- **只保留最短路径**（经过连接器最少）
- **多条等长最短路径**全部保留，传输电力**均摊**到各条路径

### 连接器负载

每个连接器会记录每刻传输的电量。这是一项性能指标，为后续过载机制提供数据基础。每刻结束后负载值归零。

### 货运管理器用电

货运管理器已接入电网，作为**用电器**运行：

- **初始容量**：128 J
- **每接入一个输入节点**：容量增加 4 J
- **每次传输消耗**：96 J（16信道固定部分）+ 输入节点数 × 2 J
- **电力不足时**：货运管理器悬浮字显示电力不足信息，物品传输被跳过
- **电力恢复后**：自动恢复正常传输
- **容量变化无需等待电网重新初始化**，实时生效

## 五、动态响应

### 放置机器

- 当您放置一个能接入电网的机器时，系统会自动搜索附近连接器
- 搜索范围 = 电网内**最大连接器的连接范围**
- 找到连接器且验证通过后，**触发电网重新初始化**
- 重新初始化期间电网不可用，完成后恢复

### 拆除机器

- 非调节器：触发电网重新初始化
- 调节器：**整个电网直接销毁**！所有机器失去电网归属

### 电网冲突

- 两个电网的调节器互相连接 → 显示"电网冲突：多个能源调节器相连"
- 机器已被其他电网占用 → 显示"电网冲突：该机器已属于其他电网"

## 六、管理员指令

### 查看电网信息

```
/sf grid info
```

输出内容：

- 调节器位置
- 电网状态（初始化中/已就绪/未初始化）
- 成员统计（发电机/电容器/用电器/连接器数量）
- 路径统计（发电机路径/电容器路径数量）
- 小规模电网下显示具体路径详情

## 七、区块加载

电网初始化完成后，电网进入**自调度模式**：

- ✅ 电力传输、计数累加、连接器老化全部在内存中运算
- ✅ 调节器区块卸载后电网继续正常工作（不依赖区块加载）
- ✅ 玩家回到电网区域时全息自动刷新显示最新数据

## 八、与原版的差异

| 特性    | 原版粘液科技    | 新版电网系统        |
| ----- | --------- | ------------- |
| 电网结构  | 松散连接      | 集中式（以调节器为核心）  |
| 多个调节器 | 同一网络只能有一个 | 同一网络只能有一个     |
| 路径选择  | 无，直接传输    | 预计算最短路径       |
| 连接器范围 | 固定        | 按等级不同（3\~18格） |
| 连接器负载 | 无         | 有（预留过载机制）     |
| 异步初始化 | 同步        | 异步（不阻塞服务器）    |
| 区块加载  | 无         | 无需区块加载（自调度）   |
| 冲突检测  | 无         | 有（防止交叉接入）     |

## 九、常见问题

**Q：我的机器装了但没接入电网？**
A：检查连接器范围能否覆盖该机器。用电器和发电机需要连接器在其连接范围内。

**Q：电网初始化中要等多久？**
A：初始化在异步线程执行，通常瞬间完成。大型电网可能需要几秒，期间电力暂停。

**Q：两个电网能合并吗？**
A：可以！在两个电网之间放置连接器。系统会检测到冲突并重新初始化，合并成一个电网（需要先拆除其中一个调节器）。

**Q：为什么我的连接器连不上另一个连接器？**
A：检查双向范围覆盖。例如范围3和范围18，距离不能超过3（较小者的范围），因为范围3的连接器无法覆盖超过3格的距离。

**Q：长途连接器有什么用？**
A：长途连接器范围128格，可以跨越远距离连接两个分离的电网区域。但它只能连接6个方向上最近的连接器，不可直接连接发电机、用电器或电容。

**Q：长途连接器会损坏吗？**
A：会的。长途连接器现在有老化耐久机制，使用碳金能源连接器级别（512/2000/8000 J/t）的耐久数据。修复材料从合成配方中随机抽取不同物品提交修复。

**Q：连接器的耐久机制是什么？**
A：每个连接器有耐久度（0%~100%）。在 sweet 功率（甜点功率）下老化最慢，超出后老化速度递增。负载超过 peak 功率时会强制扣减耐久（过载惩罚）。右键连接器可查看当前耐久、剩余可传输总量和修复所需材料。

**Q：电量计数器怎么用？**
A：在连接器正上方一格放置电量计数器，它会自动统计经过该连接器的累计电量（负载）。全息显示使用自动单位转换（K/M/B/T/Q），右键可查看精确数值，放置者 Shift+右键可清零计数器。数据持久化，重启不丢失。

**Q：电网突然不工作了？**
A：检查调节器是否被拆除。调节器被拆 = 整个电网销毁。需要重新放置调节器。

**Q：调节器区块卸载了电网还会工作吗？**
A：会！新版本电网使用自调度机制，电力传输、计数累加和连接器老化都在内存中运算，不依赖区块加载。只要玩家曾经加载过调节器区块一次（触发了初始化），之后即使离开该区域电网也会继续运行。回到电网区域时全息会自动刷新。

**Q：长途连接器跨区电网断电了？**
A：新版本长途连接器（128格）跨区电网在调节器区块卸载后仍可正常工作。旧版本的 chunk.isLoaded 限制已通过自调度架构解除。

**Q：我的货运管理器为什么显示电力不足？**
A：货运管理器需要接入电网才能工作。请确保：
1. 电网内有发电机（太阳能、煤机等）供电
2. 货运管理器在连接器/调节器的轴向范围内
3. 电网总发电量能覆盖货运管理器的消耗（每次传输至少需要96J）
4. 可以通过查看货运管理器悬浮字确认当前电量和需求

**Q：限电器怎么用？**
A：在连接器正上方一格放置限电器（与电量计数器二选一）。右键限电器后在聊天栏输入整数值（J/t）设置该连接器的每tick最大通过电量。输入 0 禁用连接器。Shift+右键设为无限制。非放置者右键可查看当前限制值。数据持久化，重启不丢失。
