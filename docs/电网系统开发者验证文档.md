# 粘液科技电网系统 — 开发者验证文档

> 最后更新：2026-05-17 | 验证用例数：52（TC-01 \~ TC-52）

## 概述

本文档面向开发者，提供电网系统的功能验证方案，涵盖连接规则验证（轴向模式）、路径计算验证、路线组显示验证、电力传输验证、边缘场景验证等。

### TC-29：路线组显示 — `/sf grid` 等长多路径

**目标**：验证同(源,目标,跳数)的多条路径在指令中显示为路线组

**步骤**：

1. 放置调节器
2. 布局：发电机A连接两个平行连接器链到达同一个用电器B
3. 例如：A→①→②→B (距离5) 和 A→③→④→B (距离5)，跳数均为2

**预期结果**：

- [ ] `/sf grid` 看向发电机A显示：
  ```
  ▼ 发电机路由 (出发)
    → B坐标 (跳数: 2) ×2条路线
      路线 1: (①坐标)→(②坐标)
      路线 2: (③坐标)→(④坐标)
  ```
- [ ] 电力传输时，连接器负载均摊50%/50%

### TC-31：轴向连接 — 对角不可达

**目标**：验证连接器不能斜向连接非轴线上的设备

**步骤**：

1. 放置调节器
2. 放置基础连接器①（范围3）在 (0,65,0)
3. 在连接器①的对角线位置 (1,65,1) 放置用电器A（不在任何轴线上，距离=1但非轴向）
4. 在连接器①的X轴方向 (3,65,0) 放置用电器B（在轴线上，距离=3）

**预期结果**：

- [ ] 用电器A **未被**加入电网（对角线不在连接器轴线上，`isWithinRangeAxial` 返回false）
- [ ] 用电器B **被**加入电网（X轴线上，距离3≤range）
- [ ] `/sf grid` 看向发电机，只有发→①→B的路径

### TC-05：连接器间单向连接

**目标**：验证连接器间允许单向连接（高范围→低范围）

**步骤**：

1. 放置调节器
2. 放置基础连接器A（范围3）
3. 在距离A=3格处放置基础连接器B（范围3）
4. 在距离A=10格、距离B=3格处放置碳金连接器C（范围18）

**预期结果**：

- [ ] A↔B：距离3，范围3→3 ✅ 双向轴向可连接（均在X轴上）
- [ ] C→B：C范围18轴向覆盖B ✅
- [ ] 验证：`validateConnection(A, C, CONNECTOR, CONNECTOR)`
  - 正向(A→C)：`isWithinRangeAxial(A, C, 3)` → false（不在同一轴线 ❌）
  - A无法发送到C，所以A→C不存在
- [ ] 验证：`validateConnection(C, B, CONNECTOR, CONNECTOR)`
  - 正向(C→B)：`isWithinRangeAxial(C, B, 18)` → true（在同一轴线上，距离3≤18）✅
  - 不检查反向 → ✅
  - C可以发送到B

### validateConnection(loc1, loc2, type1, type2) — 单向验证 + 轴向范围

**重要变更**：所有连接器/调节器的范围检查全部使用 `isWithinRangeAxial`（6轴向），不再使用 `isWithinRange`（切比雪夫立方体）。

| type1(发送方) | type2(接收方) | 正向(type1→type2)                        | 反向(type2→type1)                        | 结果         |
| ---------- | ---------- | -------------------------------------- | -------------------------------------- | ---------- |
| CONNECTOR  | CONNECTOR  | `isWithinRangeAxial(loc1,loc2,range1)` | `true`(不验证)                            | 仅发送方范围     |
| CONNECTOR  | GENERATOR  | `isWithinRangeAxial(loc1,loc2,range1)` | `true`                                 | 连接器轴向覆盖发电机 |
| CONNECTOR  | CONSUMER   | `isWithinRangeAxial(loc1,loc2,range1)` | `true`                                 | 连接器轴向覆盖用电器 |
| CONNECTOR  | CAPACITOR  | `isWithinRangeAxial(loc1,loc2,range1)` | `true`                                 | 连接器轴向覆盖电容  |
| GENERATOR  | CONNECTOR  | `true`                                 | `isWithinRangeAxial(loc2,loc1,range2)` | 连接器轴向覆盖发电机 |
| CAPACITOR  | CONNECTOR  | `isAdjacent(loc1,loc2)`                | `isWithinRangeAxial(loc2,loc1,range2)` | 相邻+连接器覆盖   |
| CAPACITOR  | CAPACITOR  | `isAdjacent(loc1,loc2)`                | `isAdjacent(loc2,loc1)`                | 相邻（特例）     |
| CAPACITOR  | GENERATOR  | —                                      | —                                      | ❌ 无效       |
| CAPACITOR  | CONSUMER   | —                                      | —                                      | ❌ 无效       |
| CONSUMER   | 任何         | —                                      | —                                      | ❌ 无效       |
| GENERATOR  | GENERATOR  | —                                      | —                                      | ❌ 无效       |
| GENERATOR  | CONSUMER   | —                                      | —                                      | ❌ 无效       |
| GENERATOR  | CAPACITOR  | —                                      | —                                      | ❌ 无效       |

> 注意：`isWithinRangeAxial` 要求目标在源位置的同一轴线上（两个轴向差=0，第三个≤range且>0）。
> `isAdjacent` 要求曼哈顿距离=1（6方向相邻）。

### checkRangeValidation(connectorLoc, machineLoc, machineType) — 成员收集验证

所有类型统一验证：`isWithinRangeAxial(connector, machine, connector.range)`，与BFS路径计算阶段保持一致。

### getNeighbors — 路径预计算邻居搜索

| type      | 搜索目标  | 搜索范围                                                  | 验证                                                |
| --------- | ----- | ----------------------------------------------------- | ------------------------------------------------- |
| GENERATOR | 所有连接器 | 无限制                                                   | `validateConnection(GENERATOR→CONNECTOR)`         |
| GENERATOR | 调节器   | `getMaxConnectorRange()` + RANGE（**轴向**）              | 调节器视为特殊连接器                                        |
| CAPACITOR | 相邻电容  | `isAdjacent`（6方向）                                     | 直接添加                                              |
| CAPACITOR | 相邻连接器 | `isAdjacent`（6方向）                                     | `validateConnection(CAPACITOR→CONNECTOR)`         |
| CAPACITOR | 相邻调节器 | `isAdjacent`（6方向）                                     | 直接添加                                              |
| CONNECTOR | 其他连接器 | 无限制                                                   | `validateConnection(CONNECTOR↔CONNECTOR)`（仅发送方轴向） |
| CONNECTOR | 发电机   | `isWithinRangeAxial(connector, generator, connRange)` | `validateConnection(CONNECTOR→GENERATOR)`         |
| CONNECTOR | 用电器   | `isWithinRangeAxial(connector, consumer, connRange)`  | `validateConnection(CONNECTOR→CONSUMER)`          |
| CONNECTOR | 电容    | `isWithinRangeAxial(connector, capacitor, connRange)` | `validateConnection(CONNECTOR→CAPACITOR)`         |
| CONNECTOR | 调节器   | `isWithinRangeAxial(connector, regulator, connRange)` | 直接添加                                              |
| CONSUMER  | —     | —                                                     | 空集合（无出边）                                          |

### 搜索方式统一说明

| 方法                            | 搜索方式                  | 说明                              |
| ----------------------------- | --------------------- | ------------------------------- |
| `processConnector`            | 6轴向 × range           | 成员收集阶段，直线上搜索                    |
| `collectNetworkMembers` 调节器扩展 | 6轴向 × RANGE           | `6 × 6 = 36` 个位置                |
| `findShortestPathsFromSource` | 通过 `getNeighbors` 图搜索 | 所有范围检查统一使用 `isWithinRangeAxial` |
| `validateConnection` 连接器检查    | `isWithinRangeAxial`  | 连接器/调节器全部轴向验证                   |
| 电容↔连接器/调节器                    | `isAdjacent`（6方向相邻）   | 曼哈顿距离=1，对角线不可达                  |

## 关键方法调用链路（最终版）

```
onMachinePlaced(newMachineLoc)  [静态]
  → removeHologramAt(newMachineLoc)        // 清除旧悬浮字
  → isLocationInOtherGrid(newMachineLoc)?  // 冲突检测
  → 遍历所有已注册EnergyNet实例:
      → 检查调节器 RANGE=6 范围内
      → 检查所有连接器的 range 范围内
  → 找到最佳匹配电网:
      if (新机器是调节器) → 直接显示冲突 + return
      else → bestNetwork.markDirty(newMachineLoc)

markDirty(l)
  → removeHologramAt(l)
  if (调节器被拆):
    → destroyed = true, abortRequested = true
    → removeAllHolograms()
    → manager.unregisterNetwork(this)
  else:
    → conflictMode = false               // 重置冲突模式
    → initialized = false, abortRequested = true

tick(block, blockData)  [主线程]
  → conflictMode? → updateHologram("电网冲突：电网交叉") + return  // 立即停工
  → !initialized?
    → !initializing && !pendingInit? → GRID_EXECUTOR.submit(initAsync)
    → pendingInit = true
    → return
  → initialized && 有成员? → performEnergyTransfer + updateHologram

initializeNetworkAsync  [异步线程]
  → pendingInit = false
  → bfsDbQueryCount.set(0)               // 重置DB查询计数器
  → synchronized(regulator)
  → destroyed? → 退出
  → initializing = true
  → clearNetworkData()
  → abortRequested || destroyed? → 退出
  → collectNetworkMembers()              // 缓存miss时→querySlimefunItemFromDb兜底
      → 调节器6轴向扩展RANGE格 → 缓存miss? → DB查询（每10次sleep 1ms）
      → BFS: processConnector() → 缓存miss? → DB查询（每10次sleep 1ms）
      → 发现冲突？→ 标记对方电网conflictMode = true + 返回false
      → BFS: processCapacitor() → 相邻电容
      → 每20步更新一次全息进度（0%~70%）
  → abortRequested || destroyed? → 退出
  → collectResult == false? → conflictMode = true + return  // 进入冲突模式
  → precomputePaths()
      → findShortestPathsFromSource(每个generator)
          → ArrayList + head 指针（父节点回溯，无路径克隆）
          → pathContainsNode 回溯去环
          → connectorShortest 连接器剪枝
          → 每50步更新一次全息进度（70%~100%）
      → findShortestPathsFromSource(每个capacitor)
  → abortRequested || destroyed? → 退出
  → initialized = true
  → !destroyed? → runSync: updateHologram(电力差额)

ShutdownHook [JVM关闭时]
  → GRID_EXECUTOR.shutdown()
  → awaitTermination(5秒)
  → 超时? → shutdownNow()
```

## 性能指标

| 指标       | 优化前                     | 优化后                                                                       |
| -------- | ----------------------- | ------------------------------------------------------------------------- |
| BFS 内存分配 | O(分支数 × 路径长) Map/List克隆 | O(节点数) 无克隆                                                                |
| 去环复杂度    | `List.contains()` O(n)  | 回溯父链 O(n) 零对象分配                                                           |
| 连接器重复探索  | 反复探索                    | `connectorShortest` 剪枝跳过                                                  |
| 进度反馈     | 无                       | 0%-70%-100% 动态显示                                                          |
| 调节器被拆    | 异步线程可能继续操作已销毁电网         | `destroyed` 直接拦截                                                          |
| 异步任务提交   | tick 每刻提交一次 → 无限堆积      | `pendingInit` 去重 → 最多一个等待                                                 |
| 关服       | 守护线程被 JVM 强杀            | ShutdownHook 优雅终止最多等5秒                                                    |
| 冲突恢复     | 无机制，永久卡死                | `conflictMode` 停工 + `markDirty` 事件驱动恢复                                    |
| 冲突影响范围   | 仅新初始化的电网停工              | **所有关联电网**停工显示交叉                                                          |
| 区块未加载的机器 | BFS 直接跳过，永不被发现          | `getComponent` 缓存 miss → `querySlimefunItemFromDb` 数据库兜底（每10次sleep 1ms限速） |

## 关键标志位一览

| 标志               | 类型               | 作用                      |
| ---------------- | ---------------- | ----------------------- |
| `initialized`    | volatile boolean | 电网初始化是否完成               |
| `initializing`   | volatile boolean | 电网正在初始化中                |
| `pendingInit`    | volatile boolean | 已有异步任务在队列中等待，防重复提交      |
| `abortRequested` | volatile boolean | 请求打断当前初始化，异步线程检查点退出     |
| `destroyed`      | volatile boolean | 电网已销毁，异步线程不再执行任何操作      |
| `conflictMode`   | volatile boolean | 电网处于冲突状态，tick 直接停工不传输电力 |

### 常见调试问题

| 症状                                | 可能原因                 | 检查点                                                       |
| --------------------------------- | -------------------- | --------------------------------------------------------- |
| 电网一直"初始化中 XX%"                    | 初始化被反复打断             | 检查是否有机器频繁放置/拆除，查看 `abortRequested` 日志                     |
| "提交异步初始化任务" 频繁出现                  | `pendingInit` 未生效    | 检查 `pendingInit` 是否在任务开始时被清除                              |
| 发电机不供电                            | 路径计算失败               | 检查连接器轴向范围是否覆盖发电机，`/sf grid` 查看路径                          |
| 用电器不收电                            | 用电器在连接器轴范围外          | 检查 `isWithinRangeAxial(connector, consumer, range)`，必须同轴线 |
| 连接器不联通                            | 发送方轴向范围不够或不同轴线       | 检查发送方连接器的 range 及是否在同一轴线上，**不再要求反向覆盖**                    |
| 电容不工作                             | 电容未与连接器相邻（6方向）       | 检查 `isAdjacent(capacitor, connector)`，对角线连接无效             |
| 调节器显示"电网交叉"但附近没有冲突                | 其他电网标记了本电网为冲突        | 用 `/sf grid` 查看本电网和附近电网，找重叠机器                             |
| 调节器一直"电网交叉"不恢复                    | 冲突源未被移除              | 检查附近是否有其他电网的重叠机器，或等待 `markDirty` 触发                       |
| 关服时报 `RejectedExecutionException` | ShutdownHook 被关服流程覆盖 | 检查 ShutdownHook 的执行时机，考虑加回 `daemon=true`                  |
