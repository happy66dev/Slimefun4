# 粘液科技电网系统 — 开发者验证文档

## 概述

本文档面向开发者，提供电网系统的功能验证方案，涵盖连接规则验证、路径计算验证、电力传输验证、边缘场景验证等。

---

| ID | 范围 |
|----|------|
| BASIC_ENERGY_CONNECTOR | 3 |

### TC-01：基础电网搭建

**目标**：验证最简电网能否正常工作

**步骤**：
1. 放置能源调节器
2. 在调节器相邻位置放置基础连接器（范围3）
3. 在连接器3格范围内放置1个发电机和1个用电器

**预期结果**：
- [ ] 调节器显示"电网已就绪"
- [ ] `/sf grid info` 显示：发电机1、用电器1、连接器1
- [ ] 发电机能正常供电给用电器
- [ ] 全息文字显示电力差额

---

### TC-02：连接器多级串联

**目标**：验证长距离电力传输

**步骤**：
1. 放置调节器
2. 放置碳金能源连接器(①，范围18)
3. 在①范围内放置基础连接器(②，范围3)，距离不超过3
4. 在②范围内放置发电机
5. 在①范围内（但不在②范围内）放置用电器

**预期结果**：
- [ ] 电网初始化成功
- [ ] 路径：发电机→②→①→用电器
- [ ] 电力正常传输

### TC-03：18格搜索（发电机找连接器）

**目标**：验证发电机通过碳金连接器远程接入

**步骤**：
1. 放置调节器
2. 放置碳金能源连接器（范围18）
3. 在连接器范围内（但非相邻）放置发电机，距离为15格
4. 在连接器范围内放置用电器

**预期结果**：
- [ ] 验证：`validateConnection(发电机, 连接器, GENERATOR, CONNECTOR)` 
  - 正向(发电机→连接器)：`forwardValid = true`（发电机无正向限制）
  - 反向(连接器→发电机)：`isWithinRange(连接器, 发电机, 18)` → true
  - 结果：✅ 连接有效
- [ ] 发电机被成功加入电网
- [ ] 路径计算正确

### TC-05：连接器间单向连接

**目标**：验证连接器间允许单向连接（高范围→低范围）

**步骤**：
1. 放置调节器
2. 放置基础连接器A（范围3）
3. 在距离A=3格处放置基础连接器B（范围3）
4. 在距离A=10格、距离B=3格处放置碳金连接器C（范围18）

**预期结果**：
- [ ] A↔B：距离3，范围3→3 ✅ 双向可连接
- [ ] C→B：C范围18覆盖B ✅，A→C：C范围18不覆盖A（A距离C=10≤18）→ 但实际上A在C的18格范围内，所以C→A可连接
- [ ] 验证：`validateConnection(A, C, CONNECTOR, CONNECTOR)` 
  - 正向(A→C)：`isWithinRange(A, C, 3)` → false（距离10>3）❌
  - A无法发送到C，所以A→C不存在
- [ ] 验证：`validateConnection(C, B, CONNECTOR, CONNECTOR)`
  - 正向(C→B)：`isWithinRange(C, B, 18)` → true（距离3≤18）✅
  - 不检查反向 → ✅
  - C可以发送到B

## 验证规则速查表

### validateConnection(loc1, loc2, type1, type2) — 单向验证

| type1(发送方) | type2(接收方) | 正向(type1→type2) | 反向(type2→type1) | 结果 |
|---------------|---------------|-------------------|-------------------|------|
| CONNECTOR | CONNECTOR | `isWithinRange(loc1,loc2,range1)` | `true`(不验证) | 仅发送方范围 |
| CONNECTOR | GENERATOR | `isWithinRange(loc1,loc2,range1)` | `true` | 连接器覆盖发电机 |
| CONNECTOR | CONSUMER | `isWithinRange(loc1,loc2,range1)` | `true` | 连接器覆盖用电器 |
| CONNECTOR | CAPACITOR | `isWithinRange(loc1,loc2,range1)` | `true` | 连接器覆盖电容 |
| GENERATOR | CONNECTOR | `true` | `isWithinRange(loc2,loc1,range2)` | 连接器覆盖发电机 |
| CAPACITOR | CONNECTOR | `isAdjacent(loc1,loc2)` | `isWithinRange(loc2,loc1,range2)` | 相邻+连接器覆盖 |
| CAPACITOR | CAPACITOR | `isAdjacent(loc1,loc2)` | `isAdjacent(loc2,loc1)` | 相邻（特例） |
| CAPACITOR | GENERATOR | — | — | ❌ 无效 |
| CAPACITOR | CONSUMER | — | — | ❌ 无效 |
| CONSUMER | 任何 | — | — | ❌ 无效 |
| GENERATOR | GENERATOR | — | — | ❌ 无效 |
| GENERATOR | CONSUMER | — | — | ❌ 无效 |
| GENERATOR | CAPACITOR | — | — | ❌ 无效 |

### checkRangeValidation(connectorLoc, machineLoc, machineType) — 成员收集验证

| machineType | 验证 | 说明 |
|-------------|------|------|
| CONNECTOR | `isWithinRange(connector, machine, connector.range)` | 单向前向 |
| GENERATOR | `isWithinRange(connector, machine, connector.range)` | 单向前向 |
| CONSUMER | `isWithinRange(connector, machine, connector.range)` | 单向前向 |
| CAPACITOR | `isWithinRange(connector, machine, connector.range)` | 单向前向 |

### getNeighbors — 路径预计算邻居搜索

| type | 搜索目标 | 搜索范围 | 验证 |
|------|----------|----------|------|
| GENERATOR | 所有连接器 | 无限制 | `validateConnection(GENERATOR→CONNECTOR)` |
| CAPACITOR | 相邻电容 | isAdjacent | 直接添加 |
| CAPACITOR | 相邻连接器 | isAdjacent | `validateConnection(CAPACITOR→CONNECTOR)` |
| CONNECTOR | 其他连接器 | 无限制 | `validateConnection(CONNECTOR↔CONNECTOR)` |
| CONNECTOR | 发电机 | `isWithinRange(connector, generator, range)` | `validateConnection(CONNECTOR→GENERATOR)` |
| CONNECTOR | 用电器 | `isWithinRange(connector, consumer, range)` | `validateConnection(CONNECTOR→CONSUMER)` |
| CONNECTOR | 电容 | `isWithinRange(connector, capacitor, range)` | `validateConnection(CONNECTOR→CAPACITOR)` |
| CONSUMER | — | — | 空集合（无出边） |

## 关键方法调用链路

```
onMachinePlaced(newMachineLoc)
  → isLocationInOtherGrid(newMachineLoc)? → 冲突
  → getMaxConnectorRange() → 搜索范围
  → 遍历 getComponent(connectorLoc)
  → checkRangeValidation(connectorLoc, newMachineLoc, machineType)? → 通过
  → markDirty(newMachineLoc)
      → initialized = false, abortRequested = true

tick(block, blockData)
  → !initialized? → GRID_EXECUTOR.submit(initializeNetworkAsync)

initializeNetworkAsync (异步线程)
  → synchronized(regulator)
  → abortRequested? → 退出
  → initializing = true
  → clearNetworkData()
  → collectNetworkMembers()
      → BFS从调节器开始
      → processConnector() → checkRangeValidation
      → processCapacitor() → 相邻电容搜索
  → abortRequested? → 退出
  → precomputePaths()
      → findShortestPathsFromSource(每个generator)
          → getNeighbors(current, type)
          → BFS去环 + 最短路径保留
      → findShortestPathsFromSource(每个capacitor)
  → abortRequested? → 退出
  → initialized = true
  → runSync: updateHologram + loadGridChunks()
```

## 调试提示

### 观察初始化状态
- 全息文字 "初始化电网中" → 正在异步初始化
- 全息文字 "电网已就绪" → 初始化完成
- 全息文字 "&c电网冲突" → 冲突检测触发

### 观察路径
- `/sf grid info` 查看预计算路径数和具体路径
- 小规模电网（≤20条路径）自动显示详细路径信息

### 观察连接器负载
- 连接器负载在每刻记录并归零
- 可通过扩展代码输出负载数据进行验证

### 常见调试问题

| 症状 | 可能原因 | 检查点 |
|------|----------|--------|
| 电网一直"初始化中" | 初始化被反复打断 | 检查是否有机器频繁放置/拆除 |
| 发电机不供电 | 路径计算失败 | 检查连接器范围是否覆盖发电机 |
| 用电器不收电 | 用电器在连接器范围外 | 检查 `isWithinRange(connector, consumer, range)` |
| 连接器不联通 | 双向范围覆盖不足 | 检查两个连接器的range是否都≥距离 |
| 电容不工作 | 电容未与连接器相邻 | 检查 `isAdjacent(capacitor, connector)` |
