## 电网运行逻辑

### 什么是电网

电网是 Slimefun 中传输电力的核心机制喵~ 简单来说就是：**发电机产电 → 通过连接器传输 → 用电器和电容耗电/储电**。

但这个传输不是无脑分配的！电网内部会计算最短路径，优先给最近的用电器供电，还能在发电机和电容之间做电力调度喵~

### 电网核心：能源调节器

**物品名称：** `能源调节器`

每一个电网都有一个**能源调节器**作为核心喵~ 调节器不是直接传输电力的，它的作用是：

1. **管理电网成员**：自动发现范围内的连接器、发电机、电容、用电器
2. **计算路径**：自动算出每台发电机到每台用电器的最短路径
3. **调度电力**：每 tick 根据路径计算结果，分发电量
4. **冲突检测**：防止两个调节器的电网意外连接

把调节器理解为"电网的大脑"就对了喵~ 🧠

### 电网成员

电网中的方块分为四种角色喵：

| 角色 | 包含什么 | 作用 |
|------|----------|------|
| **发电机** | 煤炭发电机、岩浆发电机、生物发电机等 | 产出电力 |
| **用电器** | 电动熔炉、电动洗矿机等 | 消耗电力工作 |
| **电容** | 各级电容 | 存储多余电力 |
| **连接器** | 各种能源连接器 | 连接以上三者，传输电力 |

发电机和电容只能在边缘（终端），用电器也是终端，连接器在中间充当"电线"喵~

```
发电机 ──→ 连接器 ──→ 连接器 ──→ 用电器
   │                        │
   └──→ 电容 ──→ 连接器 ──→ 用电器
```

### 电网初始化流程

调节器放置后，电网会经历以下流程喵：

```
1. 发现阶段（同步）
   调节器从自身位置出发，BFS 搜索范围内所有连接器
   通过连接器链找到所有终端节点（发电机、电容、用电器）
   建立 nodeIndex（位置索引）、connectorNodes（连接器）、terminusNodes（终端）

2. 路径预计算阶段（异步）
   对每台发电机：BFS 计算到每台用电器的最短路径
   对每台电容：BFS 计算到每台用电器的最短路径
   对每台发电机：计算到最近电容的充电路径
   按路径长度排序，保证优先使用短路径传输

3. 就绪阶段
   初始化完成，电网开始 tick 工作
```

初始化在后台线程执行，不会冻结服务器喵~ 大型电网可能需要几秒初始化，期间不影响已有电网运行。

### 路径计算机制

电网使用 **BFS（广度优先搜索）** 计算最短路径喵。

**关键机制：**
- 每条路径记录：`源 → [连接器链] → 目标`
- 多条相同长度路径会被分组，传输时平均分配负载
- 发电机路径和电容路径分开存储
- 路径按长度排序，短路径优先使用

**BFS 优化：**
- 使用父节点回溯避免路径克隆开销
- 节点数超限制（10 万）时会提前退出
- 电网销毁或重新初始化时会中断 BFS

### 电力传输流程

每个 tick，电网会执行以下流程喵：

```
Phase 1（主线程）：收集快照
  ├── tickAllGenerators()：让所有发电机工作，记录产出
  ├── tickAllCapacitors()：电容 tick
  └── collectTickSnapshot()：收集所有组件的当前电量快照
       （发电机电荷、电容电荷、用电器电荷、连接器限制等）

Phase 2（异步线程）：计算传输
  └── computeTransfers(snapshot)：
       ├── 计算总需求（用电器缺口）
       ├── transferFromGeneratorsSnapshot：发电机 → 用电器
       ├── 如果不够：transferFromCapacitorsSnapshot：电容 → 用电器
       ├── 多余能量：storeRemainingEnergy 存储到电容
       └── 产出 TransferResult（delta 表）

Phase 3（主线程）：回写结果
  ├── applyTransferResult(result)：将 delta 写回组件
  ├── propagateToEnergyMeters()：更新电量计数器
  ├── ConnectorAgingManager.processAging()：连接器老化判定
  └── updateHologram()：更新调节器悬浮字
```

**为什么用快照机制？** 主线程收集状态、异步线程计算、主线程回写。避免在大电网中计算阻塞服务器，同时保证同一 tick 内数据一致性喵~

**传输优先级：** 发电机 → 用电器（优先） → 电容 → 用电器（不足时）

**连接器负载分配：** 如果源和目标之间有多条等长路径，总传输量平均分配给所有路径。

### 电网冲突检测

当两个不同调节器的电网通过连接器意外相连时，会发生**电网冲突**喵~

**检测机制：** 初始化时发现某个连接器属于另一个已初始化的电网，则标记为冲突。

**冲突后的行为：**
- 双方电网停止 tick
- 连接器上方显示"&c电网冲突：多个能源调节器相连"悬浮字
- 拆除冲突的连接器后，电网自动重新初始化

**如何避免冲突：** 一个电力网络中只放一个调节器喵！

## 能源系统增强

### 电量计数器

**物品名称：** `电量计数器`  
**材料：** 日光探测器

**用途：** 放在连接器正上方，统计经过该连接器的累计电量喵~

**使用方法：**
1. 把电量计数器放在连接器方块的正上方喵
2. 用万用表右键就能看到累计电量了喵
3. 计数器会一直记录经过这个连接器的所有电量，不会丢失喵~
4. 计时器的主人可以潜行+右键重置计数喵~

---

### 限电器

**物品名称：** `限电器`  
**材料：** 比较器

**用途：** 放在连接器正上方，限制经过连接器的最大负载电量喵~ 防止连接器过载损坏！

**使用方法：**
1. 把限电器放在连接器方块的正上方喵
2. **右键** 限电器：逐步增加限制值喵
3. **Shift + 右键** 限电器：取消限制（无限制）喵
4. 当负载超过限制值时，多出来的能量不会传输喵

**限制值说明：**
- 设为 0：完全阻止这个连接器传输能量喵
- 设为具体数值：限制每 tick 最大传输量（单位：J/t）喵
- 无限制：不限制（默认）喵

---

### 长途连接器

**物品名称：** `长途连接器`  
**材料：** 铁块

**属性：**
- 范围：128 格（超远！）喵
- 甜点功率：512 J/t
- 最大功率：2000 J/t
- 峰值功率：8000 J/t
- 总传输容量：7.15B J

**用途：** 用于远距离连接能源网络喵~ 只能连接到其他连接器，不能直接连机器或发电机喵。

**使用方法：**
1. 在两个能源网络之间放长途连接器喵
2. 长途连接器会自动找 128 格范围内其他最近连接器并建立连接喵
3. 注意：长途连接器会随时间老化，要定期维护喵~
4. 注意：搜寻连接器允许搜寻到损坏连接器! 并且停止搜寻!

### 连接器老化机制

**所有连接器**都会随着使用慢慢老化喵~ 老化速度取决于负载大小和使用时间！

#### 老化规则

| 负载范围 | 老化速度 | 说明 |
|----------|----------|------|
| 0 ~ 甜点功率 | 超慢喵 | 理想工作区间！ |
| 甜点功率 ~ 最大功率 | 慢慢的 | 正常使用 |
| 最大功率 ~ 峰值功率 | 有点快喵 | 高负载了！ |
| 超过峰值功率 | 超快 + 过载喵！ | 危险！会坏还会电人！ |

#### 老化状态显示

| 耐久度 | 状态 | 颜色 |
|--------|------|------|
| 80% ~ 100% | 健康 | 绿色 |
| 50% ~ 80% | 正常 | 黄色 |
| 30% ~ 50% | 磨损 | 金色 |
| 15% ~ 30% | 老化 | 红色 |
| 0% ~ 15% | 预计要坏了喵 | 深红色 |
| 0% | 已损坏 T_T | 黑色 |

#### 过载伤害

当连接器负载超过峰值功率时会发生喵：
1. 连接器耐久度飞速下降喵！
2. 连接器附近会冒出烟雾和电火花粒子喵！
3. **连接器范围内的玩家会被电击！** 伤害量取决于负载超标程度和距离喵~
4. 穿**全套防护服**的玩家可以**免疫电击伤害**喵！(｀・ω・´)b

**注意：** 创造模式和旁观模式的玩家不受伤害喵~

#### 连接器损坏

当耐久度降到 0% 时：
1. 连接器变成"已损坏"状态 T_T
2. 再也不传输能量了喵
3. 会有悬浮字提示修理材料喵

#### 修复方法

1. 右键损坏的连接器，看看要什么材料喵
2. 手拿对应的材料，右键连接器提交喵
3. 提交完所有材料后，连接器恢复 100% 耐久度喵~

**修复材料数量：**
- 耐久度 > 66%：要 1 种材料喵
- 耐久度 33% ~ 66%：要 2 种材料喵
- 耐久度 0% ~ 33%：要 3 种材料喵
- 耐久度 = 0%（坏了）：要 4 种材料喵

**修复材料来源：** 从连接器的合成配方里随机抽的喵~

## 机器损坏系统

### 损坏机制说明

机器用久了会坏喵！损坏概率随工作时间增加而增加~

**损坏概率公式：** `A × t² / (B + t²)`

其中：
- `t` = 连续工作的刻数
- `A` = 损坏概率上限（配置决定的喵）
- `B` = 缓冲参数（配置决定的喵）

**设计目标：** 平均工作寿命约 500,000 粘液刻喵~

#### 损坏时会发生什么

1. 机器停止工作喵 T_T
2. 机器上方显示"§c机器损坏"悬浮字喵
3. 从合成配方中随机抽 30% 的物品当修复材料喵

---

### 修复方法

1. **右键**损坏的机器，看看需要哪些修复材料喵
2. 手拿对应材料，**右键**机器提交喵
3. 提交完所有材料后，机器自动修复恢复工作喵~

**修复材料说明：**
- 材料从机器的合成配方里随机抽的喵
- 同一种材料可能要多个喵
- 已提交的材料会显示"✓ 已提交"喵
- 还没提交的显示"✗ 需要"喵

### 机器状态持久化

**超重要机制喵！** 机器的电量和操作进度会被保存到物品里！

#### 工作原理

1. **破坏机器时：** 如果机器有电或正在做事，会掉一个有状态数据的物品喵
2. **放置机器时：** 如果物品带着状态数据，会自动恢复电量和操作喵
3. **服务器关掉时：** 所有正在做事的机器操作会存到数据库喵
4. **服务器开起来时：** 机器第一次 tick 时会从数据库恢复操作喵

#### 状态显示

有状态的物品会在描述里显示喵：
- 当前电量 / 最大电量
- 正在做的操作类型和进度条

**示例：**
```
⇨ ⚡ 500 / 1000 J
⇨ ⚙ 铁锭 → [■■■■■□□□□□] 50%
```

#### 注意事项

- 有状态的物品**不能堆叠**喵（因为每个状态都不一样）
- 要堆叠的话用"机器状态清除器"清除状态喵
- 状态数据存在物品的 PersistentDataContainer 里喵

---

### 机器状态清除器

**物品名称：** `机器状态清除器`  
**材料：** 锻造台

**用途：** 清除机器物品上的状态数据，让它恢复可堆叠喵~

**使用方法：**
1. 把机器状态清除器放地上喵
2. 手拿带状态的机器物品喵
3. **右键**机器状态清除器喵
4. 物品的状态数据（电量、操作进度等）被清除喵
5. 物品恢复普通状态，可以堆叠了喵~

**警告：** 清除状态后电量和操作进度会永久丢失！想好了再清喵！(´;ω;｀)

## 机器反馈系统

机器在工作时会有视觉和听觉反馈喵~

### 视觉反馈

- **开始工作：** 熔炉/高炉/烟熏炉会亮起火焰喵 🔥
- **工作过程中：** 每 2 tick 产生粒子效果喵
  - 头颅方块：上方生成 4 个随机位置粒子喵
  - 其他方块：中心和侧面产生粒子喵
- **停止工作：** 熔炉/高炉/烟熏炉火焰熄灭喵

### 听觉反馈

- 工作进度到 **25%**、**50%**、**75%** 时播放音效喵
- 每个里程碑只播一次音效喵

## 常见问题 Q&A 喵~

### Q: 机器坏了怎么办喵？

A: 右键坏机器看要什么材料，手拿材料右键提交就能修好喵~

### Q: 连接器坏了怎么办喵？

A: 右键坏连接器看要什么材料，手拿材料右键提交就能修好喵~

### Q: 怎么避免连接器过载喵？

A: 用限电器限制连接器的最大负载，别让负载超过峰值功率喵！

### Q: 机器状态物品能堆叠吗喵？

A: 不行喵！每个有状态的物品都有独特的电量和进度，没法堆叠喵。要堆叠就用机器状态清除器清除状态喵~

### Q: 服务器重启后机器操作会丢吗喵？

A: 不会丢喵！所有正在做的机器操作会在关服时存到数据库，重开时自动恢复喵~

### Q: 怎么查看电网信息喵？

A: 用万用表右键电网组件，或者用 `/sf grid` 命令喵~

### Q: 连接器老化能减慢吗喵？

A: 把负载控制在甜点功率以下就能极大减慢老化喵~

### Q: 过载伤害能避免吗喵？

A: 可以喵！方法有：
1. 用限电器防止过载喵
2. **穿上全套防护服可以免疫电击伤害喵！** (๑•̀ㅂ•́)و✧

### Q: 一个电力网络能放多个调节器吗喵？

A: **绝对不能喵！** 多个调节器会导致电网冲突，全部停止工作喵！一个网络只能放一个调节器喵~

### Q: 电网为什么有时候要初始化几秒喵？

A: 大电网收集成员和计算路径需要时间喵，这个计算在后台跑不会卡服务器，请耐心等一下喵~
